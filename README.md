# EyePay

**EyePay** — это специализированное Android-приложение, разработанное для обеспечения финансовой независимости *незрячих и слабовидящих пользователей*. Программа использует технологии компьютерного зрения для быстрого и безопасного распознавания платежных средств в режиме реального времени. Все ключевые вычислительные процессы выполняются *локально* на устройстве.

### Целевая аудитория и назначение
Приложение создано для людей с полной или частичной потерей зрения. Основная цель проекта — решить проблемы при проведении повседневных расчетов, минимизировать риск ошибок или мошенничества со стороны третьих лиц, а также предоставить удобный инструмент для упорядочивания личных банковских карт без необходимости визуального контроля.

### Основной функционал
1. Интеллектуальное распознавание платежных средств
2. Бесконтактный модуль NFC
3. Защищенный менеджер карт (CRUD)
4. Адаптивный доступный интерфейс 
5. Гибкие настройки приватности

### Технологический стек
Язык программирования: Kotlin.
Архитектура: MVVM, State Production (Flow/StateFlow).
Интерфейс: Jetpack Compose, Material 3.
Работа с камерой: CameraX API.
Машинное обучение: YOLO, TensorFlowLite, Google ML Kit.
База данных и безопасность: Room, SQLCipher, Android Keystore API.

### Инструкция по запуску
#### Запуск проекта через Android Studio

1. Клонирование репозитория:
```sh
git clone https://github.com/asyanix/EyePay
```

2. Открытие проекта:

Запустите Android Studio, выберите пункт Open и укажите путь к корневой папке склонированного репозитория.

3. Подготовка устройства:

Рекомендуется использовать физическое Android-устройство (минимальная версия Android 8.0 / API 26), так как эмуляторы не поддерживают эмуляцию аппаратного модуля NFC и могут иметь ограничения при работе с CameraX API.

4. Запуск:

Выберите подключенное устройство в верхней панели Android Studio и нажмите кнопку Run 'app'.

#### Установка через готовый APK-файл

1. Перенесите скачанный APK-файл на память Android-устройства.

2. Запустите APK-файл через любой файловый менеджер на устройстве.

3. Если система безопасности Android заблокирует установку, перейдите в появившемся окне в настройки и активируйте пункт «Разрешить установку из этого источника».

4. Дождитесь завершения установки и запустите приложение EyePay с экрана устройства. При первом запуске предоставьте необходимые разрешения для использования Камеры.
